# The labs on Distributed programming technologies subject.

This is an archive af lab works on Distributed programming technologies elective subject in Polish-Japanese Academy of Information Technologies. It features Spring projects on different topics.

## Reference List

1. Spring_Introduction - Introduction to Spring. Not much.
2. FlashCardsCLI - Language Cards application using CSV file in CLI.
3. FlashCardsCLI_DB_EntityManager or SpringData - Same Cards, but implemented using H2 database. Two implementations, one using Entity Manager, the other using Spring DATA JPA.
4. Blog_DB_CLI - Blog Database CLI Database First Approach.
5. Books_DB_CLI - Books Database CLI Code First Approach.
6. Web_Introduction - Intro to Spring Web and use of HTML with it.
7. DataFaker - First project Having a basic FrontEnd. Uses javafaker library to generate fake data according to options selected.
8. CodeFormatter + Bootstrap - Code formatter utility using google java code formatter. Allows for saving code snippets into the database for a specified period of time. Second implementation using Bootstrap for the looks.
9. API_BMI&BMR - Introduction to Rest API in Spring, simple api for calculating body mass index.
10. LinkRedirectAPI and GUI - Website and REST API for shortening links, both private and public.
